# Gramado Aroma --- Figma AI Design Context & Master Prompt

## 1. Project Overview

Create a **premium, editorial, luxury e-commerce website design** for
**Gramado Aroma**, a Brazilian fragrance and home-aroma brand.

Gramado Aroma sells products designed to make homes feel more elegant,
peaceful, warm, and memorable. The visual identity should communicate:

-   Luxury
-   Calmness
-   Sophistication
-   Warmth
-   Premium craftsmanship
-   Sensory experience
-   Minimal Brazilian elegance
-   Home and self-care
-   Natural fragrance
-   Boutique / editorial aesthetics

The website must feel like a **high-end fragrance, interior-design, and
lifestyle brand**, not like a generic Shopify/e-commerce template.

The design should be highly visual, spacious, refined, and immersive
while remaining fast, usable, accessible, and conversion-focused.

# 22. Required Motion System

Use:

### Page transitions

Smooth fade + vertical movement.

### Text reveal

Text should reveal using:

-   opacity
-   slight vertical movement
-   clipping/masking

### Image reveal

Use:

-   masked image reveal
-   scale from approximately 1.05 → 1
-   opacity
-   subtle movement

### Parallax

Large lifestyle images should move at a slower rate than foreground
content.

Use multiple depth layers:

-   background
-   image
-   decorative line
-   typography
-   foreground product

### Product hover

On hover:

-   image slightly scales
-   metadata moves subtly
-   CTA appears
-   background changes slightly
-   shadow increases very subtly

Avoid exaggerated animations.

### Navigation

Navbar should transition elegantly between:

-   transparent hero state
-   solid background state

Use blur only if it fits the reference ZIP.
